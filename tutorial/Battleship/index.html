Tutoriel rapide

  1. Choisis un mode : eau, touché ou coulé.
  2. Clique sur les cases de la grille.
  3. Quand un bateau est coulé, les cases autour deviennent automatiquement de l’eau.
  4. Le solveur calcule toutes les positions possibles des bateaux restants.
  5. La case jaune est le meilleur tir conseillé.
